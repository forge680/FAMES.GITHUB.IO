# Precision Forge

Mechanical Engineering Association — Website Design Prompt

Create a premium, modern, highly responsive website for a Student Mechanical Engineering Association.

The website should feel like a combination of:

Modern mechanical engineering

Precision / CAD / technical drawings

University student innovation

Professional engineering organization

Minimal Swiss-style web design

Use the uploaded Mechanical Engineering Association logo as the primary brand/logo reference.

Use the uploaded clean engineering website screenshot as the visual inspiration for layout, spacing, typography, technical grid systems, and minimal UI.

1. Overall Design Direction

The website must NOT look like a generic college website.

It should look like a professional mechanical engineering organization website.

Design keywords:

PRECISION — MOTION — ENGINEERING — INNOVATION — BUILD — CREATE

Use a very clean visual system with:

Off-white / white background

Charcoal / near-black typography

Steel gray secondary elements

Very subtle technical grid

Small amounts of engineering orange as an accent

Thin 1px borders

Large typography

Generous whitespace

Mechanical CAD-style line drawings

Technical annotations

Dimension lines

Circles, arcs, gears and geometric construction lines

Avoid excessive gradients, glassmorphism, neon colors, excessive shadows, or generic startup illustrations.

The aesthetic should feel engineered rather than decorative.

2. Color System

Primary:

Off White: #F5F4F0

White: #FFFFFF

Charcoal: #111111

Steel Gray: #777777

Light Gray: #E5E5E2

Accent:

Engineering Orange: #D95F24

Use orange sparingly for:

CTA buttons

Active navigation

Small technical markers

Hover states

Important numbers

Section indicators

The majority of the interface should remain monochrome.

3. Typography

Use a modern engineering/editorial sans-serif font.

Recommended:

Inter

Geist

Space Grotesk

IBM Plex Sans

Use:

Extremely large headlines

Tight letter spacing

Strong hierarchy

Small uppercase technical labels

Example:

could appear extremely large across the hero.

Use technical labels such as:

MEA / 2026

ENGINEERING • DESIGN • INNOVATION

EST. 20XX

01 / 06

The website should feel premium and controlled.

19. RESPONSIVE DESIGN

The website must be fully responsive.

Desktop:

Large editorial layouts

Large mechanical hero

Multi-column project grids

Tablet:

Adapt grids

Maintain whitespace

Mobile:

Clean single-column layout

Large readable typography

Touch-friendly buttons

Simplified mechanical animations

Hamburger navigation

Do not simply shrink the desktop design.

Create a proper mobile experience.

20. UX REQUIREMENTS

The website should feel extremely polished.

Prioritize:

Fast loading

Clear navigation

Accessibility

Strong typography

Good contrast

Responsive layouts

Smooth scrolling

Semantic HTML

SEO-friendly structure

Use reusable components.

Keep spacing consistent throughout the entire website.

Final Design Goal

Make the website immediately communicate:

“This is mechanical engineering.”

But communicate it through precision, typography, CAD geometry, machinery and whitespace, rather than filling the page with gears and random mechanical icons.

The final aesthetic should be:

Minimal × Mechanical × Technical × Premium × Student Innovation
